## How I work

1. **Define the real problem** — clarify the user, workflow, constraints, and evidence required before choosing a solution.
2. **Design the decision path** — make states, handoffs, exceptions, approvals, and recovery visible in the experience.
3. **Direct AI-assisted implementation** — use AI development tools to build full-stack prototypes while reviewing structure, behavior, and product boundaries.
4. **Verify before shipping** — test the working product, challenge failure paths, inspect privacy and data handling, and decide what is ready to release.
